# MDESops

- **[`certisc-lib/`](certisc-lib/)**: `certisc`, a library for certified supervisory control, with a formally verified Rust backend. Install and use: [certisc-lib/README.md](certisc-lib/README.md). Development (Rust core, tests, proofs): [certisc-lib/DEVELOPING.md](certisc-lib/DEVELOPING.md).
- **[`certisc-proof/`](certisc-proof/)**: Lean 4 proofs of those algorithms. See [certisc-proof/README.md](certisc-proof/README.md).
- **[`legacy/`](legacy/)**: the original `DESops` library and the archived Nagini code, kept for reference and comparison.
