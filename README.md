# MDESops

- **[`certisc-lib/`](certisc-lib/)**: `certisc`, a library for certified supervisory control. Its algorithms are verified with Nagini. See [certisc-lib/README.md](certisc-lib/README.md).
- **[`certisc-proof/`](certisc-proof/)**: Lean 4 proofs of those algorithms. See [certisc-proof/README.md](certisc-proof/README.md).
- **[`legacy/`](legacy/)**: the original `DESops` library, kept for reference and comparison.
